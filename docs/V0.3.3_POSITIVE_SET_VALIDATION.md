# v0.3.3 Positive Set-level Validation

## 목적

V3.3은 `26년 운항.xlsx`의 `26어획` 이벤트 좌표를
기존 일단위 조업보고와 별도로 다루는 버전이다.

현재 확보된 set-level 성격의 데이터는
날짜·선박·조업방법·좌표·어획량을 포함하지만,
실패 투망의 GPS 위치와 정확한 투망시각은 포함하지 않는다.

따라서 실패 위치를 임의 생성하지 않고
**양수 어획 이벤트 내부의 어획량 및 Ranking 검증**만 수행한다.

## 왜 성공/실패 분류를 하지 않는가

`26조업`에는 일자/선박/방법별 투망횟수가 존재하지만,
`26어획` 좌표 이벤트 수보다 투망횟수가 더 많은 구간이 있다.

이 차이는 다음 가능성을 포함한다.

- 무어획/실패 투망
- 위치가 기록되지 않은 투망
- 날짜/집계 기준 차이
- 기타 기록 정합성 차이

위치가 없는 투망을 임의 좌표에 배치하면
negative sample을 조작하게 되므로 V3.3에서는 금지한다.

따라서 다음은 하지 않는다.

- set-level ROC-AUC
- set-level 성공확률
- 실패 좌표 추정값을 이용한 분류 학습

## 26어획 파서

`src/setlevel.py`는 `26어획`의 이벤트 블록을 자동 탐색한다.

주요 컬럼:

- event_no
- date
- lat_raw / lon_raw
- vessel
- method
- catch_total
- catch_sj
- catch_yf
- catch_be

좌표는 다음과 같은 DMM 표기를 지원한다.

    S04-08
    W165-18
    S0529
    E15958

방향 문자가 누락된 값은 임의로 E/W/N/S를 추정하지 않고
invalid coordinate로 처리한다.

## 26조업 투망횟수

`load_2026_operation_counts()`는 `26조업`의
일자 × 선박 × 방법별 SC / PA / LOG 투망횟수를 long format으로 변환한다.

이 값과 좌표 이벤트 수를 비교해:

    reported_sets - coordinate_event_rows

를 진단한다.

이 값은 `unlocated_set_gap`이며
**실패 투망 수라고 단정하지 않는다.**

## 예측 Target

기본 Target은 `catch_total`.

양수 어획 이벤트 내부에서
“어느 성공 이벤트가 상대적으로 더 많은 어획을 냈는가”를 본다.

모델은 CatBoostRegressor이고
target은 `log1p(catch_total)`로 학습 후 원단위로 복원한다.

## Baseline

학습구간의 조업방법별 median 어획량을 baseline으로 사용한다.

새로운 방법이 검증구간에 등장하면
전체 학습구간 median으로 fallback한다.

## 지표

### MAE / Median AE

어획량 자체의 수치 오차.

`delta_mae = model_mae - baseline_mae`

음수일수록 단순 baseline보다 개선.

### Rank correlation

실제 어획량 순위와 모델 예측 순위의 상관.

성공 이벤트 중 상대적으로 큰 어획을
얼마나 잘 앞쪽으로 정렬하는지 확인한다.

### Top10 / Top20 Catch Lift

예측점수 상위 10% 또는 20% 이벤트의 실제 평균 어획량을
전체 검증 이벤트 평균과 비교한다.

1보다 크면 상위 후보 Ranking에 신호가 있다는 뜻이다.

## Set-level Copernicus

생성 명령:

    python scripts/build_setlevel_ocean_features.py --input "data/26년 운항.xlsx"

저장:

    data/external/processed/setlevel_2026_ocean_features.parquet

기존 일단위 Feature Store와 캐시를 분리한다.

V3.3은 정확한 투망시각이 없으므로
현재와 동일한 일자료 기반 Copernicus만 사용한다.

## 해석 범위

V3.3 결과로 말할 수 있는 것:

> 좌표가 있는 어획 이벤트들 중 상대적으로 큰 어획을
> 위치·계절·방법·선박·일별 해양환경으로 Ranking할 수 있는가?

V3.3 결과로 말할 수 없는 것:

> 이 좌표에 가면 참치가 잡힐 확률은 몇 %인가?

후자는 실패 투망의 실제 GPS 위치가 확보된 뒤
새로운 분류 문제로 설계해야 한다.
