# v0.3.1 Ocean Ablation

## 목적

V3에서 Copernicus Marine 외부 해양자료를 추가한 결과,
성공/실패 ROC-AUC는 일관되게 크게 개선되지 않았지만
일부 연도에서 Top10 Catch Lift 개선이 관찰되었다.

V3.1은 외부 데이터를 다시 늘리는 버전이 아니라
**어떤 해양변수가 실제로 성능 변화에 기여했는지 분해해서 검증하는 버전**이다.

## 비교 원칙

Ablation에서 가장 중요한 원칙은 동일표본 비교다.

예를 들어 SST 효과를 검증할 때:

    SST 값이 존재하는 조업행만 선택
            |
            +-- Baseline: 기존 V2 변수
            |
            +-- Enhanced: 기존 V2 변수 + SST

두 모델은 동일한 학습행과 검증행을 사용한다.

따라서 SST 결측치 때문에 표본 자체가 달라져 생기는 성능 차이를
SST 효과로 오해하는 문제를 줄인다.

## 지표

### delta_auc

    enhanced ROC-AUC - baseline ROC-AUC

양수면 해당 해양변수를 넣었을 때 성공/실패 구분력이 상승했다.

### delta_top10

    enhanced Top10 Lift - baseline Top10 Lift

양수면 해당 해양변수를 넣었을 때
모델 점수 상위 10%의 실제 평균 어획량 선별력이 상승했다.

PoC 목적상 후보 어장 Ranking을 생각하면 특히 중요한 지표다.

### delta_mae

    enhanced MAE - baseline MAE

음수면 해당 해양변수를 넣었을 때
성공 조업의 어획량 예측오차가 감소했다.

## 2026 단일 검증

`2026 기준 Ablation 실행`은 기본 temporal split을 사용한다.

    2023~2025 학습
    2026 검증

각 해양변수가 최신 검증연도에 미친 효과를 빠르게 확인한다.

## Walk-forward

`Walk-forward Ablation 실행`은 그룹별로 다음을 반복한다.

    2023 -> 2024
    2023~2024 -> 2025
    2023~2025 -> 2026

단일 연도에서만 delta_top10이 크게 오른 경우
그 변수가 안정적인 신호라고 단정하지 않는다.

여러 연도에서 방향과 크기가 반복되는지 확인한다.

## Parquet Viewer

Ocean Data 탭에서
`fishing_ocean_features.parquet`을 직접 조회할 수 있다.

제공 기능:

- 컬럼 설명
- 완료/미완료 필터
- 오류만 보기
- 최대 1,000행 화면 조회
- 현재 필터 결과 CSV 다운로드

Parquet은 해양환경 Feature Store이며 예측결과 파일이 아니다.

## 다음 판단

V3.1 결과에 따라 다음 단계가 달라진다.

### 특정 변수가 여러 연도에서 반복 개선

해당 변수를 우선 유지하고
투망시각/시간단위 외부데이터를 추가 검증한다.

### 전체 변수는 개선하지만 단일 변수는 불안정

변수 상호작용 가능성을 검토한다.

### 대부분 개선 없음

외부 일자료의 한계를 인정하고
GPS/AIS, FAD/부이, sonar, 정확한 투망시각 등
운영/행동 데이터를 우선 검토한다.
