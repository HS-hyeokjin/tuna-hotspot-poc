# v0.2.0 Model Validation

## 목적

V1의 단일 CatBoost 결과가 실제 해양환경 신호인지, 아니면 조업방법·선박·선장 효과를 학습한 결과인지 분리해서 확인한다.

핵심 질문:

> 조업방법·선박·선장 정보를 제거하거나 School Fish만 분리해도 위치·수온·조류에 어획 신호가 남는가?

## 실험군

| 실험 | 설명 |
|---|---|
| 전체 · 모든 변수 | V1과 유사한 전체 기준 모델 |
| 전체 · 위치/환경 Only | 선박·선장·조업방법 제거 |
| School Fish · 모든 변수 | School Fish 단독 투망만 분석 |
| School Fish · 위치/환경 Only | School Fish에서 환경 신호만 검증 |
| PA · 모든 변수 | PA 단독 투망 별도 분석 |

표본이 부족한 실험은 독립 모델을 억지로 학습하지 않고 자동 제외한다.

## 평가 지표

- ROC-AUC: 성공/실패 순위 구분력
- PR-AUC: 성공 클래스 중심 분류 성능
- Brier Score: 성공확률의 확률 오차
- MAE / Median AE: 성공 시 어획량 예측 오차
- Top 10% / 20% Catch Lift: 모델 상위 후보의 실제 평균 어획량이 전체 평균 대비 몇 배인지
- SHAP: 각 변수가 모델 예측을 어느 방향으로 밀었는지 확인

## Walk-forward

연도별로 미래를 흉내 낸다.

- 2023 학습 → 2024 검증
- 2023~2024 학습 → 2025 검증
- 2023~2025 학습 → 2026 검증

한 번의 랜덤 분할보다 실제 미래 적용 가능성을 엄격하게 본다.

## 어종별 모델

S/J, Y/F, B/E를 별도 Target으로 검증한다.

표본이 적거나 성공/실패 클래스가 한쪽으로 몰린 경우에는 해당 모델 결과를 확정적으로 해석하지 않는다.

## V3 진행 기준

다음 조건이 확인되면 외부 해양데이터 결합으로 진행한다.

1. 위치/환경 Only 또는 School Fish 위치/환경 Only 모델에서 랜덤보다 일관되게 높은 분류력이 확인됨
2. Top-K Catch Lift가 여러 연도에서 1보다 안정적으로 높음
3. 특정 연도·선박·선장 한 그룹에만 성능이 의존하지 않음

V3 후보 데이터:

- SST
- SST Gradient / Thermal Front
- Chlorophyll-a
- Current U/V
- Sea Surface Height / Eddy
- Wind
- Wave

외부 데이터를 추가한 뒤 V2 대비 실제 성능 개선 여부를 동일한 Walk-forward 방식으로 비교한다.
